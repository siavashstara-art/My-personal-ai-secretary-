# Personal AI Creative Studio (Android)

Android Kotlin + Jetpack Compose application rewritten from the Personal AI Creative Studio project, expanded with an active bilingual Personal & Phone Secretary and a GitHub / Termux Developer Companion.

## Implemented Features
- **Personal & Phone Secretary (`SecretaryScreen`)**: Bilingual (Persian & English) call-greeting and missed-call reply generator powered by Firebase AI Logic (`gemini-3.8-flash`), call-note log with AI reply drafting, daily task list, and zero-permission system Dialer, SMS, and Calendar intents.
- **GitHub & Coding Apps Hub (`DevHubScreen`)**: Live GitHub REST API client displaying user profile, recent activity events, and repositories; targeted `<queries>` detection and launcher for Termux, Termux:API, GitHub Mobile, Acode, Spck Editor, and Dcoder; and ready-to-copy Termux/Git commands.
- **Creative Studio (`CreativeStudioScreen`)**: Port of the Project Charter, Security & Privacy Principles, Modules A–F configurators (Character Studio, Virtual Try-On, Fashion & Editorial, Wedding & Formal Wear, Scene & Story, Basic Image & Video Tools), and Tech & Reality Check.
- **Gemini Studio AI (`GeminiStudioScreen`)**: Streaming Gemini AI prompt and concept generator with App Check integration.
